# SimpleCalculator

A small command-line calculator written in C++17. This project is intended as a test project for learning Git and GitHub.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Handles division by zero
- Checks that the two inputs are valid numbers

## Requirements

- A C++ compiler such as `g++` or MinGW-w64
- Git

## Compile and run on Linux or WSL

```bash
g++ -Wall -Wextra -std=c++17 main.cpp -o calculator
./calculator
```

## Compile and run on Windows (MinGW-w64)

```powershell
g++ -Wall -Wextra -std=c++17 main.cpp -o calculator.exe
.\calculator.exe
```

## Example

```text
=== Simple Calculator ===
Enter first number: 10
Enter operation (+, -, *, /): *
Enter second number: 5
Result: 50
```
